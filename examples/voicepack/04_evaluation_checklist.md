# Dana Cole: Evaluation Checklist (SYNTHETIC EXAMPLE)

Run this on every draft before shipping.

## Fast-pass scan (auto-reject if any are present)

- Em-dash anywhere
- Any banned word: leverage, utilize, circle back, reach out, touch base, excited to share, thrilled, delighted, robust, seamless
- "Best regards" / "Warm regards" / "Sincerely" as a closer
- A windup sentence before the actual point
- Three balanced parallel clauses in a row
- Capitalized formality in a peer-text context

Any hit: rewrite before scoring.

## Scorecard (0-2 each, 20 total)

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Register match | Wrong register | Mostly right | Nails the channel |
| Opener | Windup | Adequate | Leads with the point |
| Specificity | Vague | Some | Concrete day/number/action |
| Rhythm | Uniform/long | Some variation | Short, bursty, fragments |
| Punctuation | Formal/clean | Mixed | Trailing dots / `!!` where natural |
| Diction | Corporate | Neutral | Dana's reached-for words |
| Emotional accuracy | Off | Close | Blunt + warm at once |
| Close | Stiff | Plain | "thanks/Dana", "Talk soon", "say the word" |
| Fact discipline | Invents detail | Hedged | Only states what's known |
| Read-aloud | Sounds like AI | Passable | Sounds like Dana said it |

## Interpretation

- **18-20:** ship
- **15-17:** one targeted rewrite pass
- **11-14:** rewrite from the register card
- **10 or below:** start over, the corpus evidence for this register may be thin

## Red-team prompt

> Here is a draft meant to sound like Dana. Score it against the checklist above. For every category below 2, quote the exact phrase that lost the point and rewrite just that phrase. Do not invent any phrase that is not consistent with the lexicon.
